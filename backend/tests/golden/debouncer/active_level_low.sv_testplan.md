# Debouncer — Test Plan

A debouncer that filters a noisy/bouncy input into a stable output: q only updates to d_in's value after d_in has disagreed with q for 65536 consecutive clock cycles.

_Generated by SemiCraft 0.1.0 — config hash `d6bc08b67e58`. Derived from `debouncer`'s `ExplanationDoc`, `port_groups()`, and `tb_spec()`; the Test Plan table mirrors exactly what `debouncer_tb.sv` drives and checks._

## Features Under Test

Configuration exercised by this test plan:

- Counter width: 16 bits (debounce period = 2^16 = 65536 clock cycles)
- Active level: low (idle value = 0)
- Reset: sync, active-low
- Output language: SystemVerilog

**Reset behavior:** The active-low (asserted when 0) reset clears the disagreement counter and forces q to its idle value (0 (idle-low)) synchronously on the rising clock edge while reset is asserted.

## Not Covered / Limitations

- d_in is assumed synchronous to clk. If d_in originates from a mechanical switch/button wired directly to an FPGA pin, it is asynchronous to any clock; add an external 2-flop synchronizer (see the cdc-synchronizer snippet) upstream of this debouncer to avoid metastability.
- The debounce period (65536 cycles) is fixed by counter_width at generation time; it cannot be changed at runtime.
- There is no output indicating that a debounce is currently in progress; q simply updates once the period elapses.
- Directed, not randomized: the smoke TB only runs the fixed vectors in `TbSpec.vectors`; no constrained-random or exhaustive stimulus is attempted.
- Default parameterization only: the generated TB instantiates the DUT with no parameter overrides, so only the exact configuration used to generate this file is exercised. A different parameterization of the same RTL is not covered by this TB.
- Single clock/reset domain only: this TB drives one free-running clock and (if present) one reset; it performs no clock-domain-crossing verification.
- No `Check` samples cycle 0 (the first cycle after reset release): reset behavior runs structurally but is not directly self-checked by this TB.
