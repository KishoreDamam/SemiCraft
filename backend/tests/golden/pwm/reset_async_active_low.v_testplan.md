# PWM Generator — Test Plan

A 8-bit PWM generator: a free-running counter compared against a runtime input (duty) produces pwm_out, active-high, with a 256-cycle period.

_Generated by SemiCraft 0.4.0 — config hash `a7071cf49b64`. Derived from `pwm`'s `ExplanationDoc`, `port_groups()`, and `tb_spec()`; the Test Plan table mirrors exactly what `pwm_tb.sv` drives and checks._

## Features Under Test

Configuration exercised by this test plan:

- Resolution: 8 bits (period = 2^8 = 256 cycles)
- Duty-cycle source: a runtime input (duty)
- Output polarity: active-high
- Reset: async, active-low
- Output language: Verilog-2001

**Reset behavior:** The active-low (asserted when 0) reset clears the period counter to 0 asynchronously on assertion of reset (independent of the clock); pwm_out (combinational) follows immediately from the reset counter value and duty.

## Test Plan

One row per directed cycle that carries a `Check` (cycle indices are 0-based, counted from the first cycle after reset release — matching `generate_tb`'s own `checks_by_cycle` grouping). Every row is a directed, self-checking assertion emitted as an `if (sig !== expected) $fatal(...)` in the generated TB.

## Not Covered / Limitations

- duty=0 makes the (uninverted) output constant low for the whole period (constant high when invert_output is set), since cnt is never less than 0.
- duty=255 (the maximum representable value) yields the output high for 255 of the 256 counter values — one cycle short of 100% duty, since the comparison is strict (cnt < duty), not cnt <= duty.
- No dead-time, phase-shift, or center-aligned modes; this is a single-channel, edge-aligned PWM only.
- Directed, not randomized: the smoke TB only runs the fixed vectors in `TbSpec.vectors`; no constrained-random or exhaustive stimulus is attempted.
- Default parameterization only: the generated TB instantiates the DUT with no parameter overrides, so only the exact configuration used to generate this file is exercised. A different parameterization of the same RTL is not covered by this TB.
- Single clock/reset domain only: this TB drives one free-running clock and (if present) one reset; it performs no clock-domain-crossing verification.
