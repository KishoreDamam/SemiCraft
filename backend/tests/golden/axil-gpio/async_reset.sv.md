### Pins

Pad-facing signals. There is no bidirectional net: the output enable is separate so the integrator instantiates the tri-state buffer.

| Port | Direction | Description |
| --- | --- | --- |
| `gpio_in` | input | Asynchronous pin inputs; synchronised through 2 flip-flops before reaching IN. |
| `gpio_out` | output | Pin output values, straight from the OUT register. |
| `gpio_oe` | output | Pin output enables, straight from the DIR register. |

## Register map

`GPIO` — 32-bit data, 4-bit byte address (16 B decoded, 12 B used), 4-byte stride. Offsets are relative to the IP's base address.

| Offset | Name | Reset | Description |
| --- | --- | --- | --- |
| `0x00` | `DIR` | `0x00000000` | Per-pin direction; 1 drives the pin. |
| `0x04` | `OUT` | `0x00000000` | Per-pin output value, driven where DIR is 1. |
| `0x08` | `IN` | `0x00000000` | Synchronised pin input. |

Reset values are as *software* reads them, so a write-only (WO) field contributes zero.

### `DIR` — offset `0x00`

Per-pin direction; 1 drives the pin.

| Bits | Field | Access | Reset | Description |
| --- | --- | --- | --- | --- |
| `[7:0]` | `value` | RW | `0x00` | Per-pin direction; 1 drives the pin. |

Bits not listed above are reserved and read as zero. What a write to them does is the register block's policy — see the IP's own documentation.

## Configuration

- Pins: 8
- Input synchroniser: 2 stages
- Registers: 3 (16 B decoded, 12 B used)
- Reset: async, active-low (fixed by AXI4-Lite)
- Output language: SystemVerilog

## Assumptions

- gpio_in is asynchronous to aclk and is synchronised before use; a pin change takes input_sync_stages clocks to appear in IN.
- The integrator instantiates the tri-state buffer, driving the pad from gpio_out when gpio_oe is high.

## Limitations

- No interrupt on pin change: IN must be polled.
- No per-pin open-drain or pull configuration.
- No bidirectional port — the IR has no `inout`, so direction is exposed as a separate gpio_oe output.
- Bits above num_pins are reserved in every register; writing one returns SLVERR (the register block's standard policy).
