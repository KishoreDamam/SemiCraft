# AXI4-Lite timer

An AXI4-Lite timer with a 32-bit down-counter and a 16-bit prescaler, running one-shot or periodically and raising a maskable interrupt on expiry. The AXI frontend is the register-block generator spliced in rather than instantiated, so the result is one flat module.

## Register map

`TIMER` — 32-bit data, 5-bit byte address (32 B decoded, 20 B used), 4-byte stride. Offsets are relative to the IP's base address.

| Offset | Name | Reset | Description |
| --- | --- | --- | --- |
| `0x00` | `CTRL` | `0x00000000` | Run control and interrupt mask. |
| `0x04` | `RELOAD` | `0x00000000` | Value loaded into COUNT at start and at expiry. |
| `0x08` | `COUNT` | `0x00000000` | The live down-counter. |
| `0x0C` | `PRESCALE` | `0x00000000` | Clock divider ahead of the counter. |
| `0x10` | `STATUS` | `0x00000000` | Expiry flag; write 1 to clear. |

Reset values are as *software* reads them, so a write-only (WO) field contributes zero.

### `CTRL` — offset `0x00`

Run control and interrupt mask.

| Bits | Field | Access | Reset | Description |
| --- | --- | --- | --- | --- |
| `[2]` | `irq_enable` | RW | `0x0` | 1 lets STATUS.expired drive the irq output. |
| `[1]` | `auto_reload` | RW | `0x0` | 1 restarts at expiry (periodic); 0 stops (one-shot). |
| `[0]` | `enable` | RW | `0x0` | 1 runs the counter; 0 holds it reloaded. |

Bits not listed above are reserved and read as zero. What a write to them does is the register block's policy — see the IP's own documentation.

### `RELOAD` — offset `0x04`

| Bits | Field | Access | Reset | Description |
| --- | --- | --- | --- | --- |
| `[31:0]` | `value` | RW | `0x00000000` | Terminal count; the period is RELOAD+1 ticks. |

### `COUNT` — offset `0x08`

The live down-counter.

| Bits | Field | Access | Reset | Description |
| --- | --- | --- | --- | --- |

## Configuration

- Counter: 32 bits
- Prescaler: 16 bits
- Period: (RELOAD + 1) * (PRESCALE + 1) clocks
- Registers: 5 (32 B decoded, 20 B used)
- Reset: sync, active-low (fixed by AXI4-Lite)
- Output language: SystemVerilog

## Assumptions

- Software programs PRESCALE and RELOAD before setting CTRL.enable; enabling always starts a full period.
- The interrupt is level-sensitive and stays asserted until software writes 1 to STATUS.expired.

## Limitations

- No pause and resume: clearing CTRL.enable reloads the counter rather than freezing it.
- No capture or compare channels, and no free-running mode — COUNT counts down to zero and is not writable.
- STATUS.expired does not count missed expiries: a second expiry before software clears the flag is indistinguishable from the first.
- irq rises two clocks after the counter reaches its terminal count (one to sample the set request, one for the flag to be readable).
- Bits above counter_width are reserved in RELOAD and COUNT, and bits above 2 in CTRL; writing one returns SLVERR.
