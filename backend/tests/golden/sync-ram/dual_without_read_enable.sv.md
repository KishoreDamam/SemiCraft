# Synchronous RAM

A 256-word by 8-bit synchronous RAM in simple dual-port configuration. Reads are registered, and a read of the address being written in the same cycle returns the previous contents.

_Generated by SemiCraft 0.3.0 — config hash `3744a15536c5`._

## Ports

### Clocking

Single clock; the RAM has no reset (see Limitations).

| Port | Direction | Description |

### Read port

Registered read; shares the write address in single-port mode.

| Port | Direction | Description |

| `dout` | output | Registered read data, valid the cycle after the read. |

## Configuration

- Width: 8 bits
- Depth: 256 words (power of two; 8-bit address)
- Port mode: simple dual-port
- Read enable: no (dout reloads every cycle)
- Output language: SystemVerilog

## Assumptions

- One clock drives both ports; this is not a dual-clock memory.
- Depth is a power of two, so every address decodes to real storage.
- The consumer treats dout as valid one cycle after the read it issued, not in the same cycle.

## Limitations

- Read-during-write at the same address returns the OLD contents (READ_FIRST). If write-first behaviour is wanted, the reader must bypass the write data externally.
- No reset, so dout is undefined until the first read completes — X in a four-state simulator, zero in Verilator.
- No byte write enables: a write updates the whole word.
- True dual-port (two independent read/write ports, or two clocks) is not offered; simple dual-port means one write and one read port on a single clock.
- No initialisation: the array powers up undefined. A ROM with defined contents needs memory initialisation, which the IR does not yet express.
