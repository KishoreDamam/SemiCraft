# AXI4-Lite SPI Master

An AXI4-Lite SPI master in mode 01. Writing TXDATA performs one full-duplex 8-bit exchange: a byte goes out on mosi while a byte comes in on miso. The AXI frontend is the register-block generator spliced into this module.

## Register map

`SPI` — 32-bit data, 5-bit byte address (32 B decoded, 20 B used), 4-byte stride. Offsets are relative to the IP's base address.

| Offset | Name | Reset | Description |
| --- | --- | --- | --- |
| `0x00` | `STATUS` | `0x00000000` | Transfer status. |
| `0x04` | `CTRL` | `0x00000000` | Chip select control. |
| `0x08` | `TXDATA` | `0x00000000` | Writing this register starts one 8-bit exchange. |
| `0x0C` | `RXDATA` | `0x00000000` | The byte shifted in during the last exchange. |
| `0x10` | `CLKDIV` | `0x00000002` | sclk half period in aclk cycles. |

Reset values are as *software* reads them, so a write-only (WO) field contributes zero.

### `STATUS` — offset `0x00`

Transfer status.

| Bits | Field | Access | Reset | Description |
| --- | --- | --- | --- | --- |
| `[1]` | `rx_valid` | W1C | `0x0` | RXDATA holds a received byte; write 1 to clear. |
| `[0]` | `busy` | RO | `0x0` | An exchange is in progress. |

Bits not listed above are reserved and read as zero. What a write to them does is the register block's policy — see the IP's own documentation.

## Configuration

- SPI mode: 01 (CPOL=0, CPHA=1)
- Reset clock divisor: 2 aclk cycles per sclk half period (CLKDIV is writable at run time)
- Input synchroniser: 2 stages
- Registers: 5 (32 B decoded, 20 B used)
- Reset: sync, active-low (fixed by AXI4-Lite)
- Output language: Verilog-2001

## Assumptions

- The slave uses the same mode; CPOL/CPHA are fixed at generate time.
- Software holds CTRL.cs_assert across a multi-byte transaction and releases it afterwards — the exchange itself never touches cs_n.
- miso is sampled through a synchroniser, so it need not be phase-aligned to aclk.
- Software writes TXDATA only while STATUS.busy is clear.

## Limitations

- 8-bit transfers only, MSB first: no configurable word length and no LSB-first mode.
- CPOL/CPHA are generate-time options, not register bits — a runtime mode switch would carry both edge behaviours in hardware forever.
- Single chip select. Multiple slaves need external decoding of cs_n.
- No FIFOs: one byte in flight each way, and STATUS.rx_valid must be cleared between exchanges.
- No interrupt output; STATUS must be polled.
