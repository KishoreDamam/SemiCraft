# Synchronous FIFO

A 8-entry, 8-bit synchronous FIFO. Read and write pointers carry an extra wrap bit, so full and empty are distinguishable and the occupancy count is exact without any separate counter or saturating logic.

_Generated by SemiCraft 0.3.0 — config hash `2c34fa02cdca`._

## Ports

### Clocking

Single clock domain; reset empties the FIFO.

| Port | Direction | Description |
| --- | --- | --- |
| `clk` | input | Clock for both ports. |
| `rst_n` | input | Sync reset, active-low; empties the FIFO. |

### Write port

Producer side (bundle `wr`); writes while full are ignored.

| Port | Direction | Description |
| --- | --- | --- |
| `wr_en` | input | Write enable; the word is accepted unless full. |
| `wr_data` | input | Write data. |
| `full` | output | High when all entries are occupied; writes are then ignored. |

### Read port

Consumer side (bundle `rd`); reads while empty are ignored.

| Port | Direction | Description |
| --- | --- | --- |
| `rd_en` | input | Read enable; a word is popped unless empty. |
| `rd_data` | output | Registered read data, valid the cycle after an accepted rd_en. |
| `empty` | output | High when no entries remain; reads are then ignored. |

## Configuration

- Width: 8 bits
- Depth: 8 entries (power of two; 3-bit index + wrap bit)
- Count output: no
- Reset: sync, active-low
- Output language: Verilog-2001

## Assumptions

- One clock drives both ports; this is not a clock-domain-crossing FIFO (see the limitations).
- Depth is a power of two, which is what makes the wrap-bit pointer comparison exact.
- The producer honours full and the consumer honours empty; the FIFO ignores violations rather than signalling them.

## Limitations

- Reads are registered (plain FIFO), so rd_data is valid the cycle after rd_en. There is no first-word-fall-through mode: FWFT is a different read contract, not a flag, and offering both behind one boolean produces a datasheet that describes neither exactly.
- Overflow and underflow are ignored silently — a write while full and a read while empty leave the FIFO untouched, with no error output to detect that it happened.
- Single clock domain only. Crossing clocks needs the gray-pointer asynchronous FIFO, which is a separate IP.
- No almost-full / almost-empty thresholds.
